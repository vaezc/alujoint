# AluJoint 搭建指南 · 第一版实施任务

## 目标

让第一次接触铝型材的用户，从「我想搭一个架子」出发，能在网站上选连接、看懂装配顺序、整理采购和加工事项。第一套完整案例用衣架 V20。验收时找一位没参与设计的读者，请他只看网站说出要买什么、哪些部位要加工、哪些件要先装，以及装好后如何检查。

## 开工前

- 阅读当前仓库的 `AGENTS.md`（如存在）、[工作约定](./工作约定.md)、[交接进度](./交接进度.md)和下表中的实现。先执行 `git status -sb`。编写此任务时，`src/data/connections.ts` 已有未提交修改，请保留并以实际工作区内容为准。
- 交接文档记录有 428 个目录条目、12 种连接展示和 V20 衣架。浏览实现后再确定当前数量。部分连接条目只有单件模型，装配示例与厂家套件的区别以各条目的来源和说明为准。
- [V13 下单前复核](./衣架V13下单前复核.md)提供设计经过和计算背景。本文的 V20 购物车数据与 V13 历史采购信息有差异，以 V20 模型和本文核对的数据为准。

## 第一版范围

### 1. 搭建指南入口与按结构选连接

- 在主界面提供可见的「搭建指南」和「模型库」入口。保留 `/?sample=clothes-rack` 及已有样品链接。指南和案例具有可直接打开的地址，刷新以后仍停留在对应内容。
- 提供五个任务入口：横梁接立柱、两根型材接长、三根型材汇在一角、安装板件、增加斜撑。每项用小图或已有关联模型标明连接位置。
- 给出实际可用的候选连接。每项说明适用型材和槽型、加工要求、螺母能否后装、紧固件从哪里装、工具从哪面进入。优先完成常用角码和内置连接的对照。厂家加工要求或适配还没有核对的字段写「待核对」，并提供已有的图档入口。
- 链接连接示例时使用当前代码中的真实样品标识。只具备单件预览的条目仍可打开，其装配步骤按验证进度展示。斜撑入口可以先借衣架案例说明固定位置、侧摆用途与前后倾覆的区别。

### 2. 把两个常见节点做成分步装配

- 选现有的角码连接与内置端面贴侧面示例。提供上一步、下一步和当前步骤说明。分步应覆盖配件预装、型材定位、最终锁紧，以及关键检视动作。
- 步骤在 3D 里高亮正在操作的零件，并说明插入方向和工具空间。复用现有视图、零件选中和模型节点。现有模型缺加工细节的内置节点，按来源标明已知的加工条件及缺失项。
- 保留原有整景旋转、取景和爆炸功能。浏览器后退、刷新、切换到别的样品后，步骤界面显示该样品的状态。

### 3. 把衣架 V20 做成首个完整案例

同一页交付结构总览、切料表、板件、五项购物车、加工核对表、装配顺序和收尾检查。用户可从「上框短梁」「嵌平底板」跳到对应连接或板件指南，再返回案例。

| 项目 | 已核对的案例数据 |
| --- | --- |
| 框架 | V20 × 1 套，外廓宽 920 × 深 440 × 高 1502 mm，含脚杯。2020 立柱 1450 mm × 4，长梁 860 mm × 4，短梁 380 mm × 4 |
| 板件 | 覆盖式顶板 900 × 420 × 12 mm。嵌平底板 858 × 378 × 12 mm，二维轮廓四角均有避让。用原稿板形，保留长直段 796 mm 和短直段 316 mm 的核对信息 |
| 上下框配件 | 当前网页重建了 32 个角码。角码位置、外形和板托分布为示意。加工表列出原稿记录的孔项，端位或用途待核处明确标出 |
| 光轴 | `BAGA-C2-A-A-N-D16-L900` × 1，Ø16 × 900 mm |
| 支座 | `BETV-C2N1-GP-D16-H50` × 2，倒装在两根顶部短梁下方，中心距 880 mm，光轴两端各伸出约 5 mm |
| 底脚紧固件 | `EDLA-S1-M4-L10` 购物车 100 颗、实装 4 颗，`TPAA-N-6-M4` 购物车 20 颗、实装 4 颗 |

建议流程为预装脚杯及上下框、校方并调整水平、放入嵌平底板、预穿光轴和两只支座、把支座锁到短梁底槽、轴居中后锁夹紧螺钉、最后装顶板。先把流程与当前结构图核对。每步写清手能否伸进去、先装哪些槽内件、哪一步检查 T 型螺母已经横跨槽肩且支座底脚压紧。待实物核对的步骤标为试装建议。

案例收尾分别写接头松动、框架弹性侧摆和前后倾覆。X 撑按用户决定留作后装，固定方式按最终摆放条件选择。挂杆弯曲计算可以作为示例，注明荷载分布、880 mm 简支跨度和估算条件。整架额定载荷、实际晃动与抗倾覆能力均待实测。

## 实现边界

复用现有 React、3D 加载和移动端界面。指南内容与现有样品通过标识关联，避免在多处复制尺寸与料号。参数化建模、自动判定承重、在线下单、账户和后端留到后续阶段。第一版集中交付可查、可读、可照着操作的指南。

## 验收标准

1. 桌面和移动端都能从主界面找到指南。测试指南、案例与原有样品地址直达、刷新、返回，移动端内容可读且无横向溢出。
2. 从五个搭建任务都能进入有效内容或样品。角码与内置连接分别展示加工要求、零件先后和工具入口，缺失的依据有明确标记。
3. 两个分步示例能前后切换，文字与零件高亮同步。切回模型库后，现有爆炸、复位、搜索和移动端面板仍可操作。
4. V20 案例能从页面直接查到切料及板件规格、采购量与实装量、加工核对事项和逐步安装流程。上框短梁与底板均能跳到对应说明。每条承重或配合结论都能看出依据和验证状态。
5. 运行 `npm run build`、`npm run lint` 和 `npm run smoke`。用真实浏览器走通指南 → 连接步骤 → V20 案例 → 返回模型库。报告实际命令、结果和页面截图。现有检查告警与新增问题分别记录。
