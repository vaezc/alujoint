## 下载链路（11 月 17–18 日管线记录）

旧脚本自己拼 `paramSelectionList`，对 TDB / TYZ 这类默认参数不全的型号会返回空 `productModel`。现在改成在页面里先真实选参数，再读 store 里的选择结果：

- 下拉（Radix）：`Input.dispatchMouseEvent` 真实指针点击，再点第一个 `[role=option]`。
- 单选：`input[type=radio].click()`。
- 范围输入（W/H/L 等）：聚焦后 `Input.insertText`，再按 `Tab` 提交。用合成 `input` 事件不会进 store。
- 选完读 `selectionData`，再依次调 selection / requestModel / getStatus / modelDownload。

该轮 STEP 重试覆盖 44 个缺件，43 个成功。TDB21 后续用 STL 补齐。

`modelType` 除了 `step` 还支持 `stl`、`igs`。STL 是坏 STEP 的兜底：

```bash
node scripts/pipeline/download_one.mjs <serial> "" stl
venv/bin/python scripts/pipeline/stl_to_glb.py <输入.stl> <输出.glb> <node名>
```

## 转换

- venv 必须用 Python 3.12：cascadio 0.1.1 没有 3.14 的 wheel。
- `CONVERT_TIMEOUT=900` 可以覆盖 `batch_convert2.py` 默认 180 秒超时。
- 3 个 STEP 在 cascadio 里三角化挂起，换了 4 组容差、OBJ 导出和 OCP 都失败：`LC-AEG15-5065-XL90`、`TDB127`、`TDB128`。最终用站点 STL 转 GLB，`glb_meta.jsonl` 的 `note` 写明了来源。
- OCP（`cadquery-ocp`）装在 venv 里做过尝试，同样挂起，当前流程不依赖它。

## 压缩

```bash
npm run compress:models            # 全量原地重写
npm run compress:models -- --dry --limit 3
```

- gltf-transform：`dedup + weld + prune + quantize + meshopt(medium)`。
- 前端不用改：drei 的 `useGLTF` 默认挂 `MeshoptDecoder`。
- 量化保留包围盒端点，目录里的 `bboxMm` 仍然有效；`bytes` / `meshes` 由 `gen_catalog.py` 读最终文件。
