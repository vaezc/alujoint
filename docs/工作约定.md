# 工作约定

阶段性任务做完，先跑和这一阶段相关的测试，再 `git commit`，然后才开始下一阶段。不要把几阶段的修改堆在工作区里一起交。

提交说明写清这一阶段验证了什么。缺模型、未验证的配合、还在下载的零件，不要写成已经完成。

推送只走已授权的 GitHub 仓库 https://github.com/vaezc/alujoint 。这个仓库是 source of truth。Origin 上的旧草稿不删除，也不再当作后续源码仓库。本地 commit 不是 GitHub 推送，报告里要分开写。

不要 force-push，不要改写已经推送的历史，不要跳过 hooks，不要改仓库可见性。
