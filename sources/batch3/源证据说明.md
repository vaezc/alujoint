## 尺寸与轴向（均来自本批 STEP / 网格，不是编造的配合）

这些轴向只供 CloudAgent 按零件本地坐标摆放，并沿安装方向做 explode。没有验证过的 mate，也没有承载或扭矩数据。

### EDLA-S1-M4-L10（DIN912 圆柱头 M4×10 全牙，SUS304 A2-70）

- 页面与 PRODUCT 名一致。STEP 单实体；cascadio 拆成本体 + 杆部特征网格（与批次2 T 型螺母相同的拆分，不是第二颗零件）。
- **不要用 VERTEX_POINT 当完整包围盒**：顶点 Y 只有 ±1.732 mm（内六角顶点），漏了 Ø7 圆柱头。网格包围盒是 **14.000 × 7.000 × 7.000 mm**。
- 螺钉轴 = 文件 **X 轴**。内六角端面在 **x = −14 mm**，头部支承面 / 头杆分界在 **x = −10 mm**（头高 4.0 mm），尖端在 **x = 0**。头半径 3.5 mm（Ø7），杆半径 2.0 mm（Ø4）。总长 14 = 4 + 10，与 DIN912 M4 头高加 L=10 的几何一致，这是测量结果，不是合格证。
- 内六角开口在 x = −14，外接半径 1.732 mm（对边 3.0 mm），深度大约到 x = −12（约 2.0 mm）。
- 沿安装方向 explode：沿 X；尖端朝前移动时走向 **+X**。
- 与图例的关系见下文：本零件是官方 EDLA 料号，但 typc「使用示例」左图印的是 `EDLG-S1-M4-L10`，不是同一颗。

### EPDA-S1W-K-4（DIN9021 M4 宽平垫，SUS304）

- PRODUCT 名与料号一致，单实体。图例左爆图标注的就是这个料号。
- VERTEX_POINT 不可用：全部顶点 y = 0，看起来像一条线。真正范围以网格和圆柱为准：**12.000 × 12.000 × 1.000 mm**，x、y ±6，z = 0～1。
- 孔轴 = 文件 **Z 轴**，中心 (0, 0)。外径 Ø12.0（r = 6.0），内径 Ø4.30（r = 2.15），厚 1.0 mm。两面都是平面环，没有哪一面朝上的几何证据。
- explode / 叠放沿 **Z**。

### EPDB-S1W-B1-4（DIN127 M4 弹垫，SUS304）

- PRODUCT 名与料号一致，单实体。图例左爆图标注的就是这个料号。
- VERTEX_POINT 不可用：Y 只有 0～1.117，不能当成弹垫自由高度或固体包围盒。网格包围盒约 **7.600 × 7.598 × 0.900 mm**。
- 孔轴 = 文件 **Z 轴**。外径 Ø7.6（r = 3.8），内径 Ø4.10（r = 2.05）。网格的 Z 只有 0 和 0.9，官方实体是 **平面开口环**，厚 0.9 mm，不是三维螺旋自由高度。网格上可见约 10° 的切口（靠近 +X），这是网格测量，不是标准开口尺寸。不要从这个文件编造自由高度、工作载荷或扭矩。
- explode / 叠放沿 **Z**。

### TPBT-G-M5-L10（T 形螺栓，页面为欧标20、M5、L=10、镀铬）

- 页面选型与下载文件名是 `TPBT-G-M5-L10`（镀铬）。STEP 的 FILE_NAME / PRODUCT 却是数字 id `2076330136992727040`，实体名是 `TPBT-D-M5-L10-1-solid1`（D 而不是 G）。GLB 节点按页面/下载 SKU 命名为 `TPBT-G-M5-L10`。不能把这份几何当成已证明与 D 不同的镀铬专用体。
- 单实体。网格包围盒与顶点包围盒一致：**10.000 × 13.200 × 6.000 mm**。三角化很密（50,218 顶点，约 2.36 MB），主要密在 T 头区域。
- 螺杆轴 = 文件 **Y 轴**。尖端在 **y = +10 mm**，T 头在 Y 负向。T 头厚 3.2 mm（y = −3.2 到约 0），沿 X 长 10 mm（±5），沿 Z 宽 6.0 mm（±3）。
- M5 杆为半径 2.5 mm 的圆柱；r≈2.5 的网格点在 y = 1.6～9.5，尖端倒角在 9.5～10。y = 0～1.6 是更宽的过渡（STEP 在 y = 1.6 还有 r = 3.0 的圆柱），这是测量，不是官方台肩标注。
- 页面写明适用欧标 20 系列，**没有单独写「槽宽系列6」**，因此不能把槽6当成已验证的页面字段。测得 T 头宽 6.000 mm 只是几何事实，也没有把螺栓插入 TXCJ 槽口的实测配合。
- 沿安装方向 explode：沿 Y；尖端朝前移动时走向 **+Y**。

## 与角码官方图例的关系（以截图原文为准）

证据：`evidence/TYZC_fastener_example_diagram.png`。

左爆图印刷的是：`EDLG-S1-M4-L10`、`EPDB-S1W-B1-4`、盖板、`EPDA-S1W-K-4`、`TYZC-X6-206-2020G`、`TPAA-N-6-M4`、`TXCJ-H6-2020`。

右爆图是另一套示例：`EDLJ-S1-M5-L10`、`TYZC-N6-206-20A`、`TPAE-D-6-M5`、`TXCJ-H6-2020`。

下载收件箱 README 曾写「图例标注的就是 EDLA / EPDA / EPDB」。核对截图后：**平垫和弹垫与左图一致**；左图螺钉印的是 **EDLG-S1-M4-L10**，与本批下载的 **EDLA-S1-M4-L10** 不是同一料号。批次1 的 TYZC ZP 配件表写的是 EDLA-S1-M4-L10。EDLA 可作圆柱头螺钉的形状示意，但不能说「使用示例」上的那颗螺钉已经按图一字不差下到。

此 4 件加上批次1/2 的型材、角座本体和 T 型螺母后，**常见角码连接所需的硬件形状基本齐了**，但仍有必须保留的替代与缺件说明：

- typc 左图还用了 `TYZC-X6-206-2020G` 和「盖板」；现有角座仍是批次1 的 H6 本体（且 ZP 勾选并未把紧固件写进 STEP）。盖板、X6 带盖角座、以及图上的 EDLG / 右侧 EDLJ 与 TPAE，都还没有作为本包资产。
